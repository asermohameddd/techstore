# TechStore — Modern E-Commerce Website

A modern and responsive **e-commerce website for smart devices and technology products**, built to provide a realistic online shopping experience with product browsing, product details, shopping cart, and checkout functionality.

🔗 **Live Demo:** https://asermohameddd.github.io/techstore/

---

##  About The Project

**TechStore** is a front-end e-commerce project designed for selling modern technology products such as smartphones, laptops, smartwatches, headphones, and accessories.

The project focuses on creating a clean, modern, and user-friendly shopping experience while demonstrating different front-end development concepts.
